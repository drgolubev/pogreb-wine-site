# Сайт ПОGREB WINE

Спиральные винные погреба под полом дома и автоматические этажерки.

## Как устроено
- `src/` — исходники: разделы страниц (`src/sections/*.html`), сборщик страниц (`src/build_pages.py`, `src/build_more.py`), статьи журнала (`src/articles.py`), стили и скрипт.
- `media/` — фото и видео.
- `build.py` — собирает готовый сайт в папку `dist/`. Запуск: `python build.py`.
- `.github/workflows/deploy.yml` — после каждого изменения в ветке `main` GitHub сам собирает сайт и публикует его.
- `bot/pending/` — заявки на правки от Telegram-бота (что просили, что поменять, статус).

## Правки
Правки вносит Telegram-бот: пишешь или говоришь ему, что поменять, он показывает «было → стало» и публикует после подтверждения. Любую правку можно откатить кнопкой в боте или через историю коммитов на GitHub.
